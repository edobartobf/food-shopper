# Dispensa

Ricettario e lista della spesa condivisi, come app installabile (PWA) per Android.
App: https://edobartobf.github.io/food-shopper/

I dati non stanno qui: stanno nel repo privato `food-shopper-data`. Decisioni e formato dei dati in [DECISIONI.md](DECISIONI.md).

Sviluppo: `npm install`, `npm run dev`, `npm test`, `npm run build`.
